## Mapconventie (ZD-0011)

Domeinmappen worden **just-in-time** aangemaakt: pas wanneer het eerste gedistilleerde kennisdocument voor een domein geschreven wordt, niet vooraf als lege structuur (git trackt lege mappen niet; lege mappen suggereren inhoud die er niet is).
