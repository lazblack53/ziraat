# knowledge/

Centrale knowledge layer (bootstrap-structuur, ZD-0010). Bestaande kennisbronnen van Ziraat blijven leidend en worden hier NIET gedupliceerd:

- Brokerrapporten: `raporlar/` (ZFG + İş Yatırım)
- Persistente lessen/besluiten: project-memory (MEMORY.md-index)
- Standaarden en processen: `blueprint/`

Deze mappen zijn bedoeld voor toekomstige gedistilleerde kennisdocumenten per domein (bijv. `investments/` voor herbruikbare beleggingsanalyses). Eén bron van waarheid per onderwerp; linken boven kopiëren (glossary: Padconventie).
